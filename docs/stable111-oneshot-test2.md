## 本轮实现

### 代码等宽字体保留原厂

原厂扫描仍归档等宽字体的路径和度量，但扫描结果不等于允许全局替换。
物理映射、XML 重写、兼容后端目标发现及组合收尾均不再覆盖代码 monospace。
暂存区的旧等宽别名会在提交前移除；逐路径保留清单防止开机补槽再次生成。
XML 的原始文件、集合 index、轴设置和 family/alias 引用保留。
MitypeMono 等时钟数字槽不按名字中的 Mono 误判为代码字体；明确的 monospace 家族声明优先。

### 字重选取和真正的可变实例

优先使用指定字重或字体包实际字重来源，包括命名的 bold/semibold 等存储项。
对于静态系统槽位，含 wght 的普通可变来源会按目标字重生成真实轮廓实例，再按原厂度量对齐。
修复 ExtraBold 被提前当成 Bold 的匹配顺序。
原厂可变容器保留可变数据，不因制作静态别名一并丢失其多字重能力。
同一来源和字重在本次任务内复用准备结果，不另开后台预热。
如果来源本来只有一个静态字重，不修改名称或 weightClass 冒充九种粗细；报告中记录缺失字重回退。
含 SVG 的可变来源沿用测试1保留策略，不执行可能损坏 SVG 字形的静态实例化。

### 补齐清单已经证明的系统/锁屏路径

原厂清单中路径、单字体面格式、覆盖及度量均有效，并具有 UI/时钟用途的未知文件名，
不再单纯因不在旧文件名表内而被最终映射器丢弃。
只处理确实存在于相应分区的路径，不跨分区虚构文件。
新增字重、可变轴、固定宽度、数字覆盖记录；旧清单兼容，新记录在可信扫描时生成。
扫描不是替换：扫描范围不因保留等宽而收缩。
仍使用当前十个运行时分区。未开启新型未知分区、图标/表情/无关脚本、集合容器的强制覆盖。
系统 TTC/OTC 或非零 index 目标保持原厂，避免把集合替换为一个单字体面。
